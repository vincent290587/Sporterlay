# Virtual world

- `godot/`: the virtual world, a Godot 4 project. See its README.
- `HANDOVER.md`: where things stand and what to do first on the Sports PC.
- `unreal/`: an earlier Unreal Engine 5 version (never compiled), kept for later.

Both only receive power from Sporterlay (`sporterlay/world.py`, UDP to localhost). Nothing
goes back, and Sporterlay works the same without them.
